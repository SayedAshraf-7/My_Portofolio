Projects

Baby Photoshop

A C++ desktop image-editing application that provides basic Photoshop-like filters, transformations, and image enhancement tools.

My role
Solo developer
Problem
Build a desktop image editor that demonstrates core image-processing concepts by implementing common photo-editing operations from scratch, with an easy-to-use graphical interface.
Solution
A custom Image class with pixel-level algorithms written in C++ using arrays and the standard library. It covers grayscale and black-and-white conversion, brightness and contrast, edge detection and enhancement, merging, blur and sharpening, flipping and rotation, inversion, cropping, and resizing. A Qt 6 GUI sits on top.
Result
A working desktop image editor that applies multiple image-processing operations through a graphical interface.
